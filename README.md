Este projeto em Python foi criado para praticar a utilização das **variáveis** e o sistema de **Entrada, Processamento e Saída** de dados.

💡O programa solicita o **nome do aparelho**, sua respectiva **potência**,  e **tempo médio** de utilização. Com isso, é calculado o **consumo mensal** e o **custo** considerando R$ 0,75 por kWh.
A fórmula utilizada para o cálculo durante o processamento é consumo_mensal = (potencia * tempo_medio * 30) / 1000. Depois, para calcular o custo, o sistema multiplica o último resultado obtido por 0.75.
Ao fim, é exibido o nome do aparelho, sua potência, o consumo mensal do cliente e o valor a ser pago por ele.

✨ Para executar o programa, basta informar os dados que são solicitados no início para a realização dos cálculos.
